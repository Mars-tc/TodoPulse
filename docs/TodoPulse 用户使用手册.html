TodoPulse 用户使用手册

统信 UOS 桌面待办应用，配套 Chromium 浏览器扩展，可一键将网页内容收藏为待办事项。本手册面向最终使用者，按"点哪、填什么、怎么用"逐步讲解全部功能。

1简介与系统要求

TodoPulse 是一款运行在统信 UOS（x86_64）上的桌面待办应用，配合浏览器扩展，让您在浏览网页时随时把想要跟进的内容变成待办。

它能帮您做什么

  • 浏览器收藏即待办：在任意网页选中文字，点右下角悬浮按钮即可生成待办，自动带上来源网页、选中文本与时间。
  • 分类与标签管理：工作 / 生活 / 学习内置分类，可自由增删改，并带颜色与数量角标。
  • 智能提醒与重复：到期弹系统通知，支持每天 / 每周 / 每月循环，重复完成后自动生成下一轮。
  • 子任务拆解：一条待办可拆分为多个子项，显示「已完成/总数」进度。
  • 悬浮窗与统计：常驻桌面的到期看板，以及完成率、趋势、分布等数据图表。

系统要求

项目要求
操作系统统信 UOS（x86_64）；亦支持 Windows / macOS（开机自启走系统 API）
桌面环境依赖通知依赖 libnotify4，并需系统通知权限
浏览器扩展Chromium 内核浏览器（Chrome / Edge / 360 极速等），支持 Manifest V3
网络本地服务仅监听 127.0.0.1，无需外网
ℹ️
数据安全所有待办存储在本地 userData/todos.db（UOS 通常为 ~/.config/TodoPulse/todos.db），不上传云端，全程离线可用。

2安装与首次启动

安装应用（UOS）

  1. 获取安装包 dist-electron/*.deb（由开发侧 npm run dist 打包生成）。
  2. 打开终端，执行安装命令：
    sudo dpkg -i dist-electron/*.deb
# 或
sudo apt install ./dist-electron/*.deb
  3. 安装脚本会在 ${HOME}/.config/TodoPulse 创建数据目录，扩展目录为 /opt/TodoPulse/resources/browser-extension/。

首次启动与获取端口 / Token

  1. 从应用菜单或启动器启动 TodoPulse。
  2. 应用自动生成配置文件 ~/.config/TodoPulse/config.json，其中包含随机生成的 port（端口，通常从 3210 起探测）与 32 位十六进制 token。
  3. 点击界面 🧩 按钮打开「浏览器扩展使用指南」，其中直接展示当前端口与 Token，并可一键打开扩展目录。
  4. 在浏览器扩展弹窗中填入端口与 Token，点击「测试连接并保存」即可，无需手动编辑 chrome.storage.local。
⚠️
扩展连不上？若扩展提示未配置端口或 Token，请先确认 TodoPulse 已启动，再在扩展弹窗中重新「测试连接并保存」。

3主界面概览

主窗口采用三栏布局，配合顶部搜索排序栏与底部状态栏。

① 左侧 · 分类侧边栏

  • 快捷视图：全部 / 未完成 / 已完成 / 今天到期 / 已逾期。
  • 分类列表：工作 / 生活 / 学习，带颜色标与待办数量角标。
  • 新增、重命名、删除分类；入口含 🧩 网页脚本。

② 顶部 · 搜索排序栏

  • 全局搜索：实时匹配标题 / 描述 / 来源网页标题 / 选中文本，高亮关键词。
  • 排序：按创建时间、截止时间、优先级，可切换升 / 降序。

③ 中部 · 待办列表

  • 每条显示分类色标、子任务进度、重复标识、关键词高亮。
  • 支持多选进行批量操作。

④ 底部 · 状态栏

  • 显示总数 / 已完成等概览信息。
  • 托盘常驻时主窗口可最小化到系统托盘。
💡
快捷视图左侧「今天到期」「已逾期」是互斥的快捷筛选，帮您一眼看清当下最该处理的事项。

4待办管理

从新建一条待办，到分类、排序、拆解子任务、设置重复与提醒，本节覆盖日常最常用的操作。

4.1 新建与编辑待办

  1. 点击主界面「+ 新建待办」（或托盘菜单「新建待办」）打开新增 / 编辑弹窗。
  2. 填写标题与描述；可设置优先级（高 / 中 / 低）、分类、截止时间与提醒。
  3. 截止时间支持直接点选，也支持自然语言输入（如「明天下午5点」），详见 4.6。
  4. 点击「保存」即入库。如需拆解任务，见 4.4 子任务。

4.2 分类与标签

  • 新建分类：在左侧侧边栏点击「+ 新建分类」，命名并选取颜色。
  • 重命名 / 删除：右键或hover分类项，可重命名、删除；删除后其下待办自动回落为「未分类」。
  • 分类带颜色标识与待办数量角标，方便快速辨识。

4.3 搜索与排序

  • 顶部搜索框输入关键词，实时在标题、描述、来源网页标题、选中文本中匹配，并高亮命中关键词。
  • 排序切换：按创建时间 / 截止时间 / 优先级，并可切换升序 / 降序。

4.4 子任务清单

  1. 在新增 / 编辑弹窗中，找到「子任务」区域，逐条添加子项。
  2. 支持勾选完成、增 / 删 / 改子项。
  3. 列表项会显示「2/5」形式的进度，直观反映完成度。

4.5 重复待办

  • 在编辑弹窗中设置重复规则：每天 / 每周 / 每月，并可指定间隔（如每 2 周）。
  • 完成当前轮次后，系统自动生成下一轮（含子任务复制），并保留历史完成记录。

4.6 自然语言时间解析

截止时间一栏支持用日常语言描述时间，基于 chrono-node（已启用中文简体 locale）自动识别，例如：

您输入识别为
9月10日今年 9 月 10 日
下周三下一个星期三
明天下午5点明天 17:00
💡
小技巧浏览器扩展收藏时，选中文本里若含时间（如「周五前提交」），也会被自动解析为截止时间。

4.7 状态筛选与批量管理

  • 状态筛选：顶部或侧栏切换「全部 / 未完成 / 已完成」。
  • 优先级筛选：按高 / 中 / 低过滤。
  • 快捷视图：「今天到期」「已逾期」一键查看。
  • 批量管理：勾选多条待办后批量删除，或「一键清除已完成项」。

5浏览器扩展一键收藏

把网页内容变成待办最便捷的方式：在浏览器里装上扩展，就能随时收藏。

加载扩展

  1. 打开 Chromium 系浏览器（Chrome / Edge / 360 极速等）。
  2. 地址栏输入 chrome://extensions，开启右上角「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择 /opt/TodoPulse/resources/browser-extension/（开发期可选源码中的 browser-extension/）。

配置端口与 Token

  1. 点击浏览器工具栏的扩展图标，在弹窗中填写端口与 Token（来自应用内 🧩 指南或 ~/.config/TodoPulse/config.json）。
  2. 点击「测试连接并保存」，还可设置默认分类与默认提醒。

一键收藏

  1. 在任意网页选中文本，页面右下角出现「加入待办」悬浮按钮。
  2. 点击后展开面板，可编辑标题、描述、优先级、分类、截止时间与提醒，确认后入库。
  3. 若命中「一键入库」脚本，悬浮按钮会变为紫色「⚡ 一键收藏」，点击直接提交。
⚠️
升级后请重新加载扩展当 manifest.json 发生变更（如新增沙箱页声明），需在 chrome://extensions 点击扩展卡片上的刷新按钮重新加载，否则自定义 JS 模式不可用；选择器模式不受影响。

6网页脚本自定义

针对常用网站（如 Jira、工单系统）编写规则，让扩展自动提取网页字段生成待办，免去手动填写。

进入脚本管理

侧边栏「🧩 网页脚本」、顶栏图标或托盘菜单均可进入。左侧脚本列表 + 右侧编辑器，支持新建、复制、删除与启用停用。

URL 规则匹配

  • 每条脚本可配置多条通配规则，如 jira.company.com/*、*.example.com。
  • 无协议头的规则自动兼容 http / https；未以 * 结尾的规则自动允许后续路径。
  • 同一网页命中多条脚本时，面板顶部提示条可下拉切换并「重新提取」。

双模式提取

CSS 选择器模式（零代码）

  • 为标题 / 描述 / 截止时间 / 优先级分别配置选择器与取值方式。
  • 取值方式：文本、HTML、链接、图片地址、表单值、自定义属性。

自定义 JS 模式

  • 编写函数体，可用 doc（网页文档）、url（网址）、selection（选中文本）三个变量。
  • 返回 { title, description, deadline, priority }。
  • 提供示例模板与语法校验。

JS 模式示例

// doc：网页文档快照（支持 querySelector 等）
// url：当前网页地址
// selection：页面上选中的文本
const titleEl = doc.querySelector('h1');
return {
  title: titleEl ? titleEl.textContent.trim() : doc.title,
  description: selection || '',
  deadline: '',
  priority: 'medium'   // high / medium / low，也支持「高 / 中 / 低」
};

两种应用方式

  • 预填面板 将提取结果填入表单供您确认修改后再提交。
  • 一键入库 直接提交，悬浮按钮切换为紫色「⚡ 一键收藏」态。
🔒
安全说明自定义 JS 在沙箱中执行：无扩展 API、无网络、无法访问真实页面 DOM，仅能操作传入的网页快照；执行超时 2 秒，结果经字段白名单与长度截断（标题 100、描述 2000、截止 200 字符）后才可用。
ℹ️
失败静默降级桌面端未运行、脚本拉取失败、执行异常或超时时，一律回退为手动填写，不影响原有收藏流程。

7到期悬浮窗

一个常驻桌面的小挂件，主窗口最小化到托盘时仍然可见，随时提醒您临近到期的事项。

外观与交互

  • 独立置顶小窗：无边框、始终置顶、可拖动、可缩放；可单独关闭。
  • 三段到期看板：已逾期（红）/ 今天到期（橙）/ 本周到期（蓝），各带数量角标，段头可折叠；逾期显示「逾期 N 天」，今天显示「N 小时后」，本周显示「明天 17:00 / 周三 09:00」等相对时间。
  • 窗内交互：勾选框直接标记完成（划线淡出后移除）；点击事项打开主窗口并按标题筛选定位；顶部刷新按钮带旋转动效。

开关、记忆与不透明度

  • 开关：设置页「📌 悬浮窗」分组与托盘菜单「到期悬浮窗」勾选项均可开关。
  • 位置记忆：移动 / 缩放停止 400ms 后自动记录，下次启动复原；显示器变化导致坐标越界时自动回落屏幕右下角。
  • 不透明度：60%–100% 可调，鼠标悬停时自动恢复 100%，兼顾常驻不遮挡与可读性。
  • 数据同步：主窗口增改删待办后，悬浮窗自动刷新；反之亦然。

8提醒与托盘常驻

到期提醒

  • 主进程按配置间隔扫描，对到点或逾期的未完成待办弹系统通知。
  • 支持提前 5 分钟 / 10 分钟 / 30 分钟 / 1 小时 / 3 小时 / 1 天提醒。
  • 去重：同一待办同一时间点只提醒一次（去重表）。
  • 免打扰：在免打扰时段内只记录不弹窗。

系统托盘常驻

  • 关闭主窗口不再退出应用，而是最小化到托盘（到期提醒才能持续工作）。
  • 托盘菜单支持：打开主界面 / 新建待办 / 查看今日待办 / 设置 / 网页脚本 / 到期悬浮窗 / 退出。
💡
彻底退出关闭窗口后应用仍常驻是预期行为；需要退出请点击托盘图标菜单中的「退出」。

9数据统计面板

用图表直观了解自己的待办完成情况与分布。

  • 指标卡：完成率、总数 / 已完成 / 逾期。
  • 趋势图：近 7 天新增与完成趋势（SVG 折线 + 面积图，带 hover 提示）。
  • 分布图：优先级分布条形图与分类分布环形图。
  • 深浅主题自适应，阅读友好。

10回收站 · 导入导出

回收站与撤销

  • 删除改为软删除进入回收站，支持单条 / 批量恢复、彻底删除、清空。
  • 删除后弹出 Toast 提供「撤销」操作，误删可立即找回。

导入导出

  • 导出 JSON：全量备份（含分类与子任务）。
  • 导入 JSON：支持 合并 与 覆盖 两种模式。
  • 导出 CSV：待办清单（带 BOM，Excel 中文不乱码）。

11设置中心

点击主界面「设置」进入，左侧分组导航，右侧内容区，改动多数即时生效。

外观主题

  • 浅色 / 深色 / 跟随系统（随系统主题实时变化）。
  • 界面密度（紧凑 / 舒适）、字号（常规 / 大 / 特大），即时预览。

提醒设置

  • 总开关、默认提前量、免打扰时段（支持跨零点）。

本地服务与扩展

  • 端口显示与修改（保存前探测冲突）。

启动与关闭

  • 开机自启（UOS 写入 ~/.config/autostart，Windows / macOS 走系统 API）。

数据管理

  • 导入（合并 / 覆盖）、导出 JSON / CSV。
  • 清空回收站与清空全部数据（需输入 DELETE 确认）。

悬浮窗 & 关于

12常见问题 FAQ

Q：better-sqlite3 原生模块错误？

A：UOS 下安装后若报错 Unable to find native module，执行 npm exec electron-rebuild -f -w better-sqlite3（或 npx electron-rebuild -f -w better-sqlite3）。

Q：扩展无法连接 / 提示未配置端口或 Token？

A：确认 TodoPulse 已启动；在扩展弹窗中填入从 ~/.config/TodoPulse/config.json（或应用内 🧩 指南弹窗）读取的 port 与 token，点击「测试连接并保存」。

Q：系统通知不显示？

A：确保已安装 libnotify4 并检查系统通知权限。到期提醒每 60 秒扫描一次，同一待办同一时间点只提醒一次。

Q：脚本没有生效？

A：依次检查：① 脚本已启用且规则能匹配当前网址；② TodoPulse 桌面端处于运行状态；③ 扩展已按上文提示重新加载过（manifest 变更后必须刷新）；④ 打开面板时顶部是否出现脚本命中提示条，失败提示会显示具体原因。

Q：悬浮窗不显示或位置错乱？

A：在设置页「📌 悬浮窗」分组或托盘菜单「到期悬浮窗」勾选项开启；若位置跑到屏幕外，关闭后重新开启会自动回落到屏幕右下角；透明背景在部分 Linux WM 下可能失效，可尝试关闭窗口特效或反馈具体环境。

Q：端口被占用？

A：应用启动时会从 3210 起自动探测可用端口；若固定端口冲突，可修改 config_store.js 中的起始端口后重启。

Q：关闭窗口后应用没退出？

A：这是预期行为——应用已最小化为系统托盘常驻（到期提醒才能持续工作）。需要退出请点击托盘图标菜单中的「退出」。

Q：升级后旧数据丢失了吗？

A：不会。结构升级为增量迁移，且首次升级会自动生成 todos.db.<日期>.bak 备份；如需回滚，用备份文件替换 todos.db 即可。
